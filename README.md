# KtoolsGui

Графический интерфейс для утилит Ktools (ktex2png и krane). Позволяет конвертировать текстуры и анимации в удобном формате с помощью кнопок, а не командной строки.

![KtoolsGui](https://img.shields.io/badge/platform-Windows-blue)
![.NET](https://img.shields.io/badge/.NET-8.0-purple)
![License](https://img.shields.io/badge/license-MIT-green)

## Возможности

- 📁 Конвертация текстур (.tex → .png)
- 🎬 Конвертация анимаций (.build.bin → .png)
- 🌐 Двуязычный интерфейс (русский / English)
- 🎨 Приятный дизайн с фоном
- 🚀 Быстрая конвертация в один клик

## Требования

- Windows 10/11
- .NET 8.0 Runtime

## Установка

1. Скачайте последнюю версию из [Releases](https://github.com/sergeikirillov511-KING/KtoolsGui/releases).
2. Распакуйте архив в любую папку.
3. Запустите `KtoolsGui.exe`.

## Использование

### Конвертация текстур

1. Откройте вкладку **📁 Текстуры**.
2. Выберите входную папку с `.tex` файлами.
3. Выберите выходную папку для `.png` файлов.
4. Нажмите **🚀 Конвертировать текстуры**.

### Конвертация анимаций

1. Откройте вкладку **🎬 Анимации**.
2. Выберите папку с `build.bin`.
3. Выберите выходную папку.
4. Нажмите **🚀 Конвертировать анимации**.
